# Student Registration Management System

A Java Full Stack web application developed to manage student registration records efficiently.

## About the Project

The Student Registration Management System is designed to simplify the process of managing student information. Users can add, view, update and delete student records through a user-friendly interface.

This project demonstrates how frontend, backend and database technologies work together in a web application.

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Java
- Spring Boot
- Spring Data JPA

**Database**
- MySQL

## Key Features

- Add new student records
- View student details
- Update existing student information
- Delete student records
- Store and manage student data using MySQL
- Simple and user-friendly interface

## How It Works

1. Users interact with the application through the frontend.
2. The backend processes the requests using Java and Spring Boot.
3. Spring Data JPA handles database operations.
4. Student information is stored and retrieved from MySQL.

## How to Run the Project

1. Clone this repository:

   `git clone https://github.com/akilandeshwarihub/student-registration-management-system.git`

2. Open the project in your IDE.

3. Make sure Java and MySQL are installed.

4. Configure your MySQL database connection.

5. Configure the database password using the `DB_PASSWORD` environment variable.

6. Run the Spring Boot application using the Maven wrapper.

## Project Objective

The main objective of this project is to gain practical experience in Java Full Stack Development and understand how frontend, backend and database technologies are integrated.

## Learning Outcomes

- Understanding frontend development
- Working with Java and Spring Boot
- Connecting applications with MySQL
- Performing CRUD operations
- Understanding full-stack application development
